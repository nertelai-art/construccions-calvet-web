# Calvet Sala Construccions — web

Portada de [Calvet Sala Construccions](http://www.construccions-calvet.com/), constructors de Torroella de Montgrí.
Next.js 16, React 19, TypeScript i CSS Modules; `three` només per a l'escena de la masia.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm check` passa typecheck, lint i tests. L'estructura, les regles i el que queda pendent són a [CLAUDE.md](CLAUDE.md).

Ara és una **demo per a un lead**: només s'obre amb un enllaç personal (`pnpm demo:link "Nom"`) i registra les visites
amb PostHog. Quan hi hagi avís legal i de galetes, haurà de dir-ho, o es treu el kit de demo (vegeu `CLAUDE.md`).

Les fotos de `public/obres` són de Calvet Sala Construccions i vénen del seu web.
